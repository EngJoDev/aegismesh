# Contributing to AegisMesh ⚡

Thank you for contributing to AegisMesh! We welcome all developers, security researchers, and DevOps engineers worldwide.

## Development Setup

1. Clone your fork:
   ```bash
   git clone https://github.com/EngJoDev/aegismesh.git
   cd aegismesh
   ```

2. Run test suite:
   ```bash
   ./.venv/bin/python -m unittest discover tests
   ```

## Pull Request Guidelines
- Add unit tests for any new threat detection signatures or rate-limiting algorithms.
- Keep the proxy core lightweight with minimal latency overhead.
- Ensure all automated unit tests pass.

Thank you for securing modern APIs and AI systems! 🛡️
